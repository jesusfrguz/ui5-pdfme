Objetivo

Qué puedes hacer

ui5-pdfme combina un diseño visual con campos proporcionados por la aplicación. El resultado es una plantilla reutilizable que puede generar muchos documentos con datos diferentes.

Diseñar

Añade textos, tablas, imágenes, firmas, formas, fechas y códigos; colócalos y ajusta sus propiedades.

Conectar

Inserta campos del panel de datos para que el documento se rellene automáticamente.

Entregar

Comprueba el PDF, guarda la plantilla y descarga o imprime el documento final.

Importante: una plantilla guarda el diseño, no las credenciales ni los permisos. La aplicación decide qué datos y repositorios puede utilizar cada persona.

5 minutos

Crear el primer documento

  1. Abre una plantilla. Pulsa Plantillas, usa los filtros si es necesario y selecciona Abrir. Si no hay catálogo, trabaja con el diseño que ha preparado la aplicación.
  2. Añade contenido. Selecciona un campo del panel izquierdo para conectarlo a datos, o elige un tipo en la paleta para crear contenido estático.
  3. Colócalo. Arrastra el elemento en el lienzo y usa sus tiradores para cambiar el tamaño.
  4. Configúralo. Selecciona el elemento y revisa sus propiedades. Usa un identificador corto, semántico y único.
  5. Comprueba el resultado. Pulsa Vista previa del PDF. Corrige el diseño hasta que los datos se lean correctamente.
  6. Guarda. Indica nombre, descripción, etiquetas, estado y repositorio cuando sea la primera vez.
Concepto clave

Campos estáticos y conectados

TipoCuándo utilizarloComportamiento
EstáticoTítulos, etiquetas, instrucciones, líneas y elementos decorativos.Conserva el contenido escrito en la plantilla y muestra un ojo en la lista. Si se repite en todas las páginas, muestra además el icono de páginas superpuestas. Valor desde datos permanece desactivado.
ConectadoCliente, fecha, importe, dirección, artículos y cualquier valor que cambie.Recibe un valor de la aplicación. Muestra el icono de base de datos y Valor desde datos está activado.

Identificador del campo

Es la clave estable que relaciona el diseño con los datos. Debe ser única en toda la plantilla. No uses el texto traducido que ve el destinatario: son preferibles nombres como customerName, invoiceDate o items.

Etiqueta y valor en un solo campo Text

En un Text conectado, activa Mostrar etiqueta y edita Texto de la etiqueta para representar un campo compacto como Subtotal: 125,50 €. La etiqueta se ve en el layout y se incluye en la vista previa y en el PDF final. En un Text estático, el flag permanece marcado y deshabilitado porque el contenido de la plantilla ya es su texto visible.

Panel de datos

  • Usa la búsqueda para localizar un campo por su ruta o valor de ejemplo.
  • Incluido indica que el diseño ya utiliza ese dato; no significa necesariamente que esté visible en la página actual.
  • No incluido indica que todavía no existe un elemento que utilice ese dato.
  • Pulsa actualizar si la aplicación ha cambiado los datos de ejemplo.
Diseños reales

Contenido avanzado

Tablas

Inserta el campo que representa la colección completa, no solamente una propiedad de la primera fila. Ajusta cabeceras, anchos y altura con ejemplos sin filas, con pocas filas y con muchas filas.

Texto con varias variables

Utilízalo para frases que combinan texto fijo y varios valores, por ejemplo un resumen con número de factura, cliente y total. Mantén cada variable disponible en los datos.

Imágenes, firmas y códigos

Reserva espacio suficiente y comprueba la calidad en el PDF generado. En Códigos y QR, elige QR, Code 128, EAN-13, Data Matrix o PDF417. Verifica cada código con un lector real antes de publicar la plantilla.

Varias páginas

Para una cabecera o un pie estático, o para un campo Text conectado a datos, activa Posición fija no desplazable. El elemento conservará sus coordenadas y quedará fuera del flujo cuando crezcan tablas o textos. Después puedes activar opcionalmente Repetir en todas las páginas; el valor resuelto del Text también se repetirá. Si no lo haces, se dibujará solo en su página original. Al generar, el borde del elemento repetido amplía automáticamente el margen superior o inferior más cercano para que el contenido que salta de página no se superponga; el margen configurado sigue siendo el mínimo. En textos estáticos repetidos puedes utilizar {currentPage} y {totalPages}. Estas opciones no se muestran para campos conectados que no sean Text ni cuando el fondo es un PDF importado.

Ciclo de vida

Guardar y recuperar plantillas

La primera vez, Guardar plantilla solicita metadatos. Las siguientes guardadas actualizan el registro abierto, salvo que la aplicación ofrezca una operación específica para crear otra versión.

DatoRecomendación
NombreDescribe el documento y, si procede, el país o idioma.
DescripciónIndica finalidad, destinatario y particularidades relevantes.
EtiquetasUsa términos consistentes para facilitar la búsqueda.
BorradorDiseño en preparación o pendiente de revisión.
PublicadaVersión aprobada para uso operativo.
ArchivadaDiseño conservado como histórico, pero no recomendado para nuevos documentos.
Cambiar el estado no sustituye una aprobación. Los permisos, revisiones y versiones disponibles dependen del sistema donde está integrado el editor.

Para configurar dónde se listan y guardan los diseños, consulta la guía técnica Catálogo y repositorios de plantillas.

Antes de publicar

Comprobar el PDF

  • Actualiza los datos y abre la vista previa.
  • Comprueba valores vacíos, textos muy largos y caracteres especiales.
  • Prueba tablas sin filas, con una fila y con muchas filas.
  • Revisa saltos de página, márgenes y contenido fuera del área imprimible.
  • Verifica idioma, fechas, zona horaria, moneda y fuentes.
  • Descarga un PDF y ábrelo fuera del editor.
  • Realiza una impresión de prueba cuando el tamaño físico sea importante.

Los navegadores muestran su propio diálogo de impresión. El editor no puede imprimir de forma silenciosa.

Ayuda

Problemas comunes

ProblemaQué hacer
No aparecen campos de datosPulsa actualizar. Si sigue vacío, la aplicación todavía no ha proporcionado datos o no tienes acceso; contacta con el responsable funcional.
Un campo queda vacío en el PDFComprueba que está conectado, que su identificador corresponde a una opción disponible y que el dato de ejemplo tiene valor.
No se acepta un identificadorElige una opción disponible para un campo conectado o utiliza un nombre único para un campo estático.
No aparecen las opciones de posición fijaSelecciona un elemento estático o un Text conectado. Estas opciones no están disponibles para otros campos conectados ni para fondos PDF importados.
La tabla desbordaAumenta su espacio, reduce columnas o texto y prueba con más filas. Revisa también la página siguiente.
No puedo guardar o publicarRevisa el repositorio y el estado seleccionados. La aplicación puede limitar estas operaciones según tus permisos.
No aparece la impresiónPermite que el PDF termine de generarse y revisa si el navegador ha bloqueado el diálogo o la nueva ventana.

Para fallos de integración, consulta los problemas técnicos.
